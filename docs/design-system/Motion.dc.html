AGORA DESIGN SYSTEM · MOTION
Animated on twos
The HUD moves like a hand-animated cel film: 12 drawings a second, hard cuts, held poses, and solid shadows that snap instead of fade. Nothing blurs, nothing tweens smoothly except the slow orbits. Each beat is a whole number of drawings (1 drawing = 83ms).
Looping demos keep running. One-shot demos replay on click.
01On twos12 drawings a second. Every timing is steps(n), never a smooth curve. Quantize in Godot: t = floor(t·12)/12.
02Hold the poseMove fast, then hold. A beat is 3–5 drawings; the held frame is what the player reads.
03Shadows snapInk shadows are on or off: 4px when resting, 0 when pressed, 8px on landing. Never faded, never blurred.
04Boil what's liveOnly the focused thing boils. One boiling element per screen, so focus is findable at a glance.
05Cut, don't fadeState changes are hard cuts or wipes. Opacity fades only for the scrim, at one drawing.

Godot implementation
AnimationPlayer tracks use Discrete update mode at 12fps keys. For code tweens, quantize progress: t = floor(t × 12 × dur) / (12 × dur). Boil: offset the StyleBox draw by a 3-entry table, swap every 83ms on the focused control only. Shadows: toggle StyleBoxFlat.shadow_size / shadow_offset between fixed values; never animate shadow_size continuously. Settings → Motion: Full / Reduced (cuts + pop only) / Off. Respect it everywhere, including the web.
